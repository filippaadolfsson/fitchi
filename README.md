# Fitchi – testversion

Spela dig friskare. En webbapp för att testa Fitchi: välj din fitchi, ta hand om den varje dag och se den spegla hur du mår.

**Öppna:** https://filippaadolfsson.github.io/fitchi/

- Lägg till på hemskärmen: Safari → Dela → *Lägg till på hemskärmen* (iPhone), eller menyn → *Installera app* (Android).
- Allt sparas bara i din egen telefon.
- Testpanelen: lägg till `?test` sist i adressen.
- Börja om från början: lägg till `?borjaom` sist i adressen.

Testversion – ingen riktig hälsodata hämtas, och mynt och förmåner är exempel.
