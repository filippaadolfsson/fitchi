Hur räknas det?

Energi = steg + pass senaste veckan. Styrka = styrkepass + protein. Vila = sömn + HRV + vilopuls + incheckning. Näring = protein + vatten + grönsaker. Tränat hårt flera dagar och låg HRV ger en vilodag. Borta i 3 dagar eller mer ger ett varmt välkommen tillbaka och lättare uppdrag. Formen bygger på snittet över flera veckor: ett steg upp per cirka 3 aktiva veckor, ett steg ner per cirka 5 inaktiva, och tillbaka till tidigare nivå går dubbelt så snabbt (muskelminne). Prylar försvinner aldrig.

Tips: gå igenom matchningen, eller använd testpanelen för att hoppa direkt till startvyn med olika scenarier.
